# Loops, conditions and parsing

Shell scripts covering Bash loops, conditional statements and parsing with `awk`.

| Script | Description |
| --- | --- |
| `1-for_best_school` | Displays `Best School` 10 times using a `for` loop |
| `2-while_best_school` | Displays `Best School` 10 times using a `while` loop |
| `3-until_best_school` | Displays `Best School` 10 times using an `until` loop |
| `4-if_9_say_hi` | Displays `Best School` 10 times, and `Hi` after the 9th iteration |
| `5-4_bad_luck_8_is_your_chance` | Displays `bad luck` on the 4th iteration, `good luck` on the 8th, and `Best School` otherwise |
| `6-superstitious_numbers` | Displays numbers from 1 to 20 with a bad luck message after 4, 9 and 17 |
| `7-clock` | Displays hours from 0 to 12 and minutes from 1 to 59 |
| `8-for_ls` | Lists the current directory, showing only the part of each name after the first dash |
| `9-to_file_or_not_to_file` | Gives information about the `school` file |
| `10-fizzbuzz` | Displays numbers from 1 to 100 as FizzBuzz |
| `11-read_and_cut` | Displays the username, user id and home directory from `/etc/passwd` |
| `12-tell_the_story_of_passwd` | Tells a story about each user in `/etc/passwd` using `IFS` |
| `13-lets_parse_apache_logs` | Displays the visitor IP and HTTP status code from `apache-access.log` |
| `14-dig_the-data` | Groups visitors by IP and HTTP status code, ordered by occurrences |
