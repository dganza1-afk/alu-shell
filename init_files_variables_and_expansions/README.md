# Init Files, Variables and Expansions

Shell scripts covering aliases, environment and local variables, arithmetic expansion and base conversion.

| Script | Description |
| --- | --- |
| `0-alias` | Creates an alias `ls` with the value `rm *` |
| `1-hello_you` | Prints `hello user`, where user is the current Linux user |
| `2-path` | Adds `/action` as the last directory of the `PATH` |
| `3-paths` | Counts the number of directories in the `PATH` |
| `4-global_variables` | Lists environment variables |
| `5-local_variables` | Lists local variables, environment variables and functions |
| `6-create_local_variable` | Creates the local variable `BEST` with the value `School` |
| `7-create_global_variable` | Creates the global variable `BEST` with the value `School` |
| `8-true_knowledge` | Prints 128 plus the value of `TRUEKNOWLEDGE` |
| `9-divide_and_rule` | Prints `POWER` divided by `DIVIDE` |
| `10-love_exponent_breath` | Prints `BREATH` to the power `LOVE` |
| `11-binary_to_decimal` | Converts `BINARY` from base 2 to base 10 |
| `12-combinations` | Prints all two-letter combinations except `oo` |
| `13-print_float` | Prints `NUM` with two decimal places |
| `14-decimal_to_hexadecimal` | Converts `DECIMAL` from base 10 to base 16 |
| `15-rot13` | Encodes and decodes text using rot13 |
| `16-odd` | Prints every other line from the input, starting with the first |
| `17-water_and_stir` | Adds `WATER` (base `water`) and `STIR` (base `stir.`), printing the result in base `bestchol` |
